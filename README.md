# scariCANO

App Flutter per gestione e download di musica con supporto USB OTG via Storage Access Framework.

## Funzionalità
- Ricerca brani da YouTube
- Download paralleli con ripresa
- Selezione destinazione (USB/SD/Interna) via SAF
- Libreria indicizzata
- Player in background con notifica media
- Preservazione metadati ID3
- Downloader semplice per URL diretti

## Requisiti
- Flutter 3.19+
- Android API 26+
- Permessi: INTERNET, FOREGROUND_SERVICE
